Plataformas

No seu sistema, do jeito certo.

Extensão nativa para GNOME. App de bandeja para Windows, KDE, XFCE e afins. A mesma lógica nos dois.

Extensão para GNOME Shell 45–49

Vive na barra superior, sem processo extra. Clique para abrir o painel; ative o widget flutuante e o velocímetro se quiser. Ubuntu, Zorin, Debian e Fedora.

  1. Clone e instale
    git clone https://github.com/tiagomeconi/ai-tracking-gnome.git && cd ai-tracking-gnome && ./scripts/install.sh
  2. Reinicie o Shell (Alt+F2 → r no X11; saia e entre no Wayland) e ative
    gnome-extensions enable ai-usage-monitor@prohound.io

App de bandeja para Windows 10/11

Fica ao lado do relógio. Clique para abrir o painel (arraste de qualquer ponto), ative o widget flutuante e inicie junto com o sistema.

  1. Precisa de Node.js 20+ e Git. Clone e rode
    git clone https://github.com/tiagomeconi/ai-tracking-gnome.git; cd ai-tracking-gnome\desktop; npm install; npm start
  2. Ou gere o instalador
    npm run dist:win

App de bandeja para KDE, XFCE e outros

Precisa de uma bandeja do sistema. No KDE Plasma 6 (Wayland) o app usa XWayland automaticamente para que painel e widget possam ser movidos. Gera AppImage e .rpm.

  1. Precisa de Node.js 20+ e Git. Clone e rode
    git clone https://github.com/tiagomeconi/ai-tracking-gnome.git && cd ai-tracking-gnome/desktop && npm install && npm start
  2. Ou gere os pacotes
    npm run dist:linux

Ainda em teste interno: o app para Windows e o clique esquerdo no KDE foram validados por colegas, e a lista de problemas conhecidos está no README.

Como funciona

Sem conta nova. Sem servidor nosso.

1

Você já fez login

Claude Code, Codex CLI e Antigravity já guardam a sessão no seu computador.

2

Lemos só na memória

O token é lido para uma única requisição aos servidores oficiais — nunca gravado nem enviado a terceiros.

3

Você vê, na hora

O painel abre do cache, atualiza em segundo plano e uma IA com erro nunca esconde as outras.

Privacidade

Seus dados ficam com você.

  • Código aberto — audite você mesmo.
  • Sem telemetria e sem servidor próprio: fala só com as APIs dos provedores.
  • Nenhuma credencial é guardada, registrada em log ou enviada para outro lugar.
  • Sem scraping e sem cookies do navegador — só o login que os CLIs oficiais já fizeram.
  • O histórico do gráfico é um arquivo local, apagado após 30 dias.

Por dentro

Claro, escuro e configurável.

FAQ

O que costumam perguntar.

Isso mostra quanto eu gastei em dinheiro?

Não. Mostra uso/cota das assinaturas — nunca valores em dinheiro.

Preciso criar uma conta?

Não. O app não tem conta própria: reaproveita o login que Claude Code, Codex CLI e Antigravity já fizeram no seu computador.

Quais IAs têm dados reais?

Claude, Codex e Antigravity mostram a cota real. O Copilot ainda usa dados de demonstração — a integração está em desenvolvimento.

Funciona no Mac?

Não é um alvo hoje: o Claude Code guarda o token no Keychain do macOS, que não é suportado.

Por que preciso reiniciar o GNOME Shell?

O Shell só recarrega o código das extensões ao reiniciar. Desligar e ligar a extensão não basta: use Alt+F2 → r (X11) ou saia e entre (Wayland).

Está pronto para o dia a dia?

Está em teste interno. Funciona e é usado, mas pode ter arestas — abra uma issue no GitHub se encontrar alguma.

Pronto para nunca mais ser pego de surpresa?

Open source, gratuito e local. Pegue no GitHub e instale em minutos.
